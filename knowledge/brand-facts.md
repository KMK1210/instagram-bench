## 디자인 DNA — @pladitor (에디토리얼 라이트 스타일, 확정)

Canva 레퍼런스 참고, 인테리어/라이프스타일 콘텐츠용. (다크 로즈우드 버전을 시험했다가 "너무 밤티(무겁다)"는 피드백으로 이 라이트 버전으로 확정됨 — 다크 버전으로 되돌리지 말 것.)

- **배경**: `#F7F4EF` (warm off-white / cream)
- **메인 텍스트**: `#1A1A1A` (near-black)
- **서브 텍스트**: `rgba(26,26,26,0.55)`
- **메인 액센트 (라이트 배경 위)**: `#7A2E3A` (딥 버건디) — 숫자 라벨, 언더라인, 화살표, 헤드라인 강조어
- **메인 액센트 (사진/다크 오버레이 위)**: `#E3A9B3` (더스티 로즈, 버건디의 밝은 버전 — 사진 위 가독성용)
- **구분선**: `rgba(26,26,26,0.15)` 1px 헤어라인
- **마스트헤드**: 매 슬라이드 상단 반복 — 좌측 카테고리 라벨("HOME STORY"), 중앙 로고 마크("( P )"), 우측 계정 핸들("@pladitor"), 아래 헤어라인
- **레이아웃 철학**: 여백 크게, 헤어라인 구분자로 섹션 분리, 넘버링은 색상 강조 숫자(01/02..)로
- **해상도**: **1080×1350 고정** (인스타 캐러셀 4:5, 바꾸지 말 것)

### 폰트 (자체 호스팅 필수 — CDN import 쓰지 말 것)

- **폰트 패밀리**: **Noto Sans KR** 단일 패밀리로 통일 (Regular 400 / Bold 700 / Black 900)
- **제목(헤드라인, 슬라이드당 1개)**: Noto Sans KR **Bold 700** (Black 900 아님 — 900은 "너무 두껍다"는 피드백으로 반려, 700이 확정 두께). 깔끔한 고딕. ⚠️ 둥글둥글한 임팩트체(Jua 등)도 반려됨 — 제목에 라운드/디스플레이 서체 쓰지 말 것. 레퍼런스: "Nomadays" 인스타 카드(사진 배경 + 굵은 고딕 인용구 헤드라인) 스타일.
- **커버(슬라이드 1) 제목 크기**: 88px (다른 슬라이드 헤드라인 44~52px보다 훨씬 큼 — "글씨 더 키워" 피드백 반영, 커버는 확대해서 임팩트 강조).
- **본문/리스트 아이템/캡션/설명**: Noto Sans KR **Regular 400** — 트렌디해 보이려면 여기는 확실히 얇게. "지금 두께가 너무 두껍다"는 피드백으로 700/600 등 중간 굵기를 전부 400으로 낮춤.
- **대비 원칙**: 슬라이드당 메인 제목 **1개만** 900으로 굵게, 나머지(리스트 소제목, 캡션, 화살표 포인트 문장 등)는 전부 400. 작은 UI 라벨(마스트헤드 "HOME STORY", "BEFORE/AFTER" 태그, 색상 강조 숫자 01/02..)은 예외로 굵게(700~800) 유지 — 이건 "내용"이 아니라 태그/아이콘 역할.
- **⚠️ 중요**: 이 세션 환경에서 `cdn.jsdelivr.net`은 조직 정책으로 **완전히 차단**되어 있어서, 기존에 쓰던 `@import url('...pretendardvariable.css')`가 매번 403으로 조용히 실패하고 시스템 기본 폰트로 폴백되고 있었음 (육안으로는 티가 안 나서 한참 몰랐음). Google Fonts 도메인(`fonts.googleapis.com`/`fonts.gstatic.com`)은 접근 가능하지만, Puppeteer가 쓰는 Chromium이 이 프록시 환경의 TLS 인증서를 신뢰하지 않아 런타임 CDN 로드가 실패함(`ERR_CERT_AUTHORITY_INVALID`).
- **해결책**: 폰트 파일을 Node의 `https` 모듈로 미리 다운로드해서 `output/<topic>/assets/fonts/*.ttf` 에 저장하고, `@font-face { src: url('../assets/fonts/파일명.ttf') }` 로 로컬 참조. 매 신규 캐러셀마다 이 폰트 파일들을 복사해서 재사용하면 됨 (네트워크 의존 없이 항상 동일하게 렌더링됨).
- 컬러 팔레트 후보로 검토했던 Lemon Chiffon `#FFF8CA` + Rosewood `#6B0B0C` (다크 버전용)는 채택하지 않음 — 참고용으로만 기록.

> 디자인 DNA는 `templates/slides.*.json` 의 `common_style` 필드에도 **동일한 값**으로 반영되어야 9장이 통일됩니다.
